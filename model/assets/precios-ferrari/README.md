# Pricing hero

`hero-ferrari-dark.png` was created with the built-in image generation tool for the standalone pricing canvas. It is generated concept imagery, not a photograph of a customer's vehicle.

Prompt:

> Use case: ads-marketing. Create one photorealistic premium automotive photograph for the wide hero of SoftRent's pricing page. A dark graphite-black Ferrari 296 GTB, recognizable correct Ferrari proportions, front three-quarter angle, entire car including both visible wheels fully in frame. Extremely elegant underground automotive studio, warm charcoal-black seamless environment (#0f0e0d), matte dark concrete floor with restrained reflections. Car positioned across center/right, occupying about 65% of image width, generous dark negative space in upper left for a heading rendered separately in HTML. Long horizontal composition, 16:9. Refined directional deep-red and burnt-orange rim lighting from off frame reveals body curves; headlights small crisp warm white, paint and wheel detail visible in the shadows, no bright red painted car. Low camera angle, sophisticated real editorial photography, realistic materials and perspective, subtle atmospheric haze only in the distance. No people, no typography, no text, no graphics, no watermarks, no added UI. Keep all edges of image almost black to blend into the dark webpage.
